# Smart Expense Tracker API

## Features
- Add Expense
- View Expenses
- Delete Expense
- Filter by Category
- Calculate Total Expenses

## Tech Stack
- Node.js
- Express.js
- JSON File Storage

## Installation

npm install

## Run

npm run dev

## Test

npm test

## API Endpoints

GET /expenses

POST /expenses

DELETE /expenses/:id

GET /expenses/filter?category=Food

GET /expenses/total

GET /expenses/total?category=Food
